## 🟡 Phase 8c — Dockerize (packaging DONE 2026-09-12, verified locally — deploy to a host remains)

Everything before this is done and verified. Code is Docker-ready; this phase is packaging + a host.

- [x] `backend/Dockerfile` — `python:3.12-slim`, non-root user, deps layer cached; gunicorn with **1 uvicorn worker** (`-k uvicorn.workers.UvicornWorker -w 1` — the in-memory rate limiter and login throttle are per-process; Redis-backed limiter is the scale-out upgrade), logs to stdout
- [x] **Proxy headers** — `FORWARDED_ALLOW_IPS=*` set in the image: uvicorn's `proxy_headers` is on by default and the env var is what both gunicorn and the uvicorn worker read for trust. Safe because the backend port is **never published publicly** — only the compose network / loopback can reach it. Behind Caddy the rate limiter sees real visitor IPs from `X-Forwarded-For`, not the proxy's IP
- [x] **CSP header** — nginx serves the frontend with `Content-Security-Policy` (`script-src 'self'` — no inline scripts exist; `style-src 'unsafe-inline'` for React inline styles; `connect-src` locked to exactly the API origin, substituted at container start via nginx's template entrypoint) + nosniff/X-Frame-Options/Referrer-Policy. The backend deliberately doesn't set CSP (JSON API). *Verified live — including the nginx gotcha that an `add_header` inside a `location` block hides all parent headers: the first version stripped the CSP from the JS bundle*
- [x] `frontend/Dockerfile` — node:22 build stage with `VITE_API_URL` build arg (API base is baked at build time in `src/api/client.js`), then nginx:1.27-alpine serving `dist/`: SPA `try_files` fallback, `expires 1y` on `/assets/` (hashed filenames), `no-cache` on `index.html`
- [x] `docker-compose.yml` — db (postgres:17-alpine, volume, healthcheck) + backend (migrates with `alembic upgrade head` then execs gunicorn; loopback-only port 8000) + frontend (loopback port **8090** — 8080/8081 are in this dev machine's Windows reserved ranges) + **Caddy** edge proxy (auto-TLS, profile `edge` — only started on the server: `docker compose --profile edge up`) + named volumes for pgdata and Caddy certs
- [x] `Caddyfile` — `SITE_DOMAIN` → frontend, `API_DOMAIN` → backend, sets X-Forwarded-*; ACME email from env
- [x] `.dockerignore` files — backend excludes `venv/`, `.env`, `tests/`, `backups/`; frontend excludes `node_modules/`, `dist/`, `e2e/`
- [x] `.env.example` (repo root) — the **single** template for every setting, read by compose, the backend and Vite: database (`PG_*` for local, `POSTGRES_*` for the container), `SECRET_KEY`, `ENVIRONMENT`, `FRONTEND_URL`, `VITE_API_URL`, `CORS_ORIGINS` (JSON array), `SMTP_*`, business config, and every operational tunable.
